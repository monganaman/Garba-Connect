# Garba Connect — NIT Kurukshetra

A student-focused Garba and Dandiya partner discovery app starter.

## Status
This repository is being set up. The app requires a Supabase project for real authentication and persistence. Do not deploy it as production-ready until access controls, private messaging, reporting/moderation, account deletion/export, and security testing are complete.

## Starter package
Use the project ZIP shared in the ChatGPT conversation for the complete initial React + TypeScript + Vite scaffold and Supabase SQL migration.
